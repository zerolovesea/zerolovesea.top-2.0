# 猫咪 logo · vector motion

打开 [logo_motion.html](./logo_motion.html)，或在项目根目录运行：

```sh
bun design/logo-motion/serve.ts
```

预览地址：http://127.0.0.1:4355/logo_motion.html

- `logo.svg`：真正的可编辑矢量，未嵌入位图。
- `logo_motion.html`：1.8 秒入场、重播、实时调速、慢动作与四个独立小动作，单文件离线可用。
- `motion.css`：主时间线；所有角色共用 1,800 ms 时钟。
- `motion_spec.md`：编排、参数、取舍与验收数据。
- `outputs/`：拟合叠图、放大图、逐帧、缓动与连续性报告、重现脚本。

没有替换现有应用的启动动画或网站图标。
