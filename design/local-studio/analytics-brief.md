# 阅读概览

目标：Tidemark 启动首页显示真实埋点数据，保持既有 Payload 应用风格。工作模式为 Operate。数据复用现有 D1 查询，不新增收集字段或公开接口。

## Direction contract

THESIS：作者打开应用即可了解选定时间段的阅读情况，再查看热门文章和访客来源。

OWN-WORLD：继承 studio.css 的字体、灰度、浅深主题、细边框、直角平面结构和博客品牌，时间选择使用已有自定义下拉。

STORY：选择时间范围，比较 PV / UV 趋势，查看热门文章、国家 / 地区、城市与浏览器语言。图中数据点提供时段与精确数值。

FIRST VIEWPORT：原侧栏和顶栏保持不动；页标题与时间、刷新控件同排，三列指标共用分隔线；趋势图占主要宽度，下方进入两列排行。

FORM：扩展既有首页，无新视觉世界或概念选择。图表使用语义 SVG 和细条；加载、无数据、错误、过期缓存均显示真实状态。缓存 15 分钟，按需查询，常驻无轮询。

FINISH：检查 macOS 实际窗口的真实数据、时间选择和 PV / UV 切换；测试缓存、鉴权、断网恢复、时间边界与安全渲染；同步应用说明和既有设计文档。
