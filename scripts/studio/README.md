# Tidemark

本地内容管理应用。沿用 Payload 后台的界面结构和博客的猫咪图标，不使用数据库，不参与线上站点部署。

## macOS 应用

双击 `~/Applications/Tidemark.app`（构建产物在 `.local-studio/`），或双击项目根目录的 `start-studio.command`。原生 AppKit 窗口、Dock 猫咪图标、菜单栏与系统文件选择器；编辑区域由系统 WebKit 渲染。无需保持终端或浏览器开启。支持 ⌘S 保存、⌘K 搜索、⌘R 重新载入和 ⌘Q 退出；关闭窗口常驻；真正退出时，未保存修改、上传与翻译会提醒。

重新构建：

```bash
bun run studio:macos:build
```

需要 Xcode command line tools。生成当前 Mac 架构的应用，最低 macOS 13。应用内置 Bun，不需要额外安装 Electron；运行时仍读取当前博客项目与其 `node_modules`，不能删除或移动原项目。项目移动后重新构建即可；应用本身可以复制到 `~/Applications`。这是本机开发签名版本，尚未做分发公证。

应用独立使用 4342 管理端口与 4343 预览端口，仅监听本机。应用自动启动服务，关闭窗口停止预览并进入常驻，退出才停止所属服务和预览；端口被其他进程占用时显示错误，不接管未知服务。API key 仍只保存在当前服务进程中，启动后在设置页填写。

## 浏览器启动（可选）

```bash
bun run studio
```

打开 http://127.0.0.1:4322 。终端窗口需要保持开启；Ctrl+C 同时关闭管理服务与预览进程。`bun run studio --open` 自动打开浏览器。默认端口 4322、隔离预览端口 4323，可通过 `STUDIO_PORT` / `STUDIO_PREVIEW_PORT` 修改。避免同时开两个管理实例编辑同一篇文章。

## 已实现

- 读取四个真实集合：writing、writing-en、thought、thought-en；支持搜索、分页、格式筛选和语言切换。
- 新建、编辑、导入 Markdown / MDX，保留未知 frontmatter 字段。发布前可保存独立草稿；输入后也会自动备份草稿。
- 保存时校验必填字段、Markdown / MDX 和公式，检查文件 revision 防止覆盖外部修改；覆盖前留存旧版本。
- 删除到回收站，可选同时删除关联英文版；恢复遇到同名文件时停止。图片不会随着文章删除。
- 编辑器直接拖入图片或粘贴剪贴板图片，也能用文件选择器批量上传。在操作位置插入引用，多图保持顺序，内容相同的图片复用，重名不同内容不覆盖。
- 中英文同 stem 文件共用 `public/_posts/<stem>/`；thought 共用 `public/_thoughts/<stem>/`。使用根路径 URL，不会因 `/en/` 路由断图。
- 资源库可查看真实引用、插入图片、移除未引用图片；移除图片会保留到本地 removed-images。
- 调用现有九个交互组件，首次插入自动转换为 MDX、补充 import，保留公式和代码。Highlight / Sidenote / RevealQuote 支持参数；其他组件使用其现有内置内容。
- 自定义 Claude 使用 Anthropic Messages 协议。长文分段生成、保留公式/代码/链接/组件结构、支持取消、显示配置模型与返回模型。输出截断或结构丢失时阻止保存。
- 真正的 Astro 预览：复制隔离源码与内容，运行原布局、原组件、KaTeX 与图集；不把未保存内容写入正式集合。有对应语言文件时，隔离预览的语言切换也正常工作。
- 站点图片查看器支持上一张/下一张、左右键、序号、首尾禁用、Escape 关闭和键盘打开。

## 使用模型

设置页预填用户指定的基础地址与模型：

```text
endpoint: https://one.iflytek.com/api/llm/console/chat
model: claude-opus-4-8
```

最终 URL 按约定追加 `/v1/messages`。输入 API key 后点击保存设置，再测试连接。key 只保存在服务进程内，不写磁盘、不回传浏览器，退出后需要重新填写。也可从环境变量 `STUDIO_LLM_API_KEY` 读取；不建议将真实密钥写进版本库。

正文会发送给你配置的服务商，图片二进制不会为翻译上传。公式、代码、链接和整个 MDX 组件作为不可改写片段保留；组件内部的文字和链接标签因此仍保留原文，可在译文校对时人工调整。

默认 `max_tokens` 为 2048，段落按预算分组。单个段落超过 8000 字符时会提示先拆段，避免静默截断；可在设置调高输出上限。图片只在剪贴板确实提供图片二进制时粘贴，纯 URL 或 `file://` 文本不会自动下载/读取。

## 文件位置

正式内容和图片沿用现有目录。应用状态都在 Git 忽略的 `.local-studio/`：

| 路径 | 用途 |
| --- | --- |
| drafts | 未发布草稿 |
| versions | 每次覆盖前的原文件快照 |
| trash | 可恢复的中英文文件包 |
| removed-images | 手动移除的未引用图片 |
| preview-端口 | 隔离 Astro 工作区与缓存 |
| model.json | 接口、模型与输出上限，不含密钥 |

文件名与标题独立：修改标题不移动共享图片。新文件可在首次上传/保存前修改文件名；保存后不提供自动改名，避免破坏原有文章链接。导入文件先成为草稿，同名保存会报告冲突，不静默覆盖。

图片写入后撤销正文插入不会删除图片，未引用图片可从资源库明确清理。图片引用检查采取保守策略，正文中同名资源会视为潜在引用。备份仅在本机，不能替代项目的异地备份。

## 常驻与系统负载

- 菜单栏使用博客猫咪图标的单色模板版本，适配 macOS 浅色/深色菜单栏。菜单栏仅保留「打开 Tidemark」「节能模式」「退出 Tidemark」。停止预览在主菜单「显示」，显示项目在主菜单「文件」。
- 关闭按钮 / ⌘W 进入常驻，窗口关闭后从 Dock 隐藏；菜单栏或重新打开应用可恢复窗口。⌘Q /「退出 Tidemark」才结束进程。常驻不代表开机启动。
- 节能常驻默认开启，设置只保存在本机偏好中。隐藏时停止隔离 Astro 服务；内容已保存且没有任务时，释放 WebKit 编辑器，恢复后重新载入先前文档、页面、筛选和主题。侧栏折叠、滚动位置等临时外观不保证恢复。
- 未保存内容、新建文档、译文校对、设置页或打开的对话框会保留编辑器，避免丢失现场。进行中的上传/翻译/编译先完成再整理；重新打开窗口会取消待处理的休眠。常驻期间模型密钥继续留在 Bun 服务内存中。
- 本地服务使用 utility QoS；Astro 预览子进程 nice=10，低于普通前台任务优先级，编译仍按队列串行。没有用于刷新状态的常驻轮询。CPU 和内存由实际内容、编译任务与 macOS 调度决定，没有硬性占用上限。

## 开启与筛选

冷启动播放约 1.9 秒的原生 Core Animation：三道潮线描绘、汇合，博客猫咪标识显现，Tidemark 字标揭示，最后淡出进入工作区。动画与本地服务启动并行，工作区未准备好时保留静态标识；不伪造加载进度。常驻唤回不重播，系统「减少动态效果」开启时改为静态标识和短淡出。无视频、外部资源、循环动画或新增运行时依赖。

博文和 thought 的格式筛选使用自定义下拉面板，支持全部 / markdown / mdx、选中状态、浅深色、键盘 Tab / Enter 和 Escape 关闭。

## 中文、组件与 AI 讨论

- 应用导航显示「内容集合 / 工具 / 随想」。磁盘上的 collection 名称与 URL 不改动。格式与高亮颜色都使用统一自定义下拉；复选框用于多选和开关。
- 组件库按需启动一个隔离 Astro 预览，展示选中组件的原始样式和交互。高亮颜色、文字与展开引用参数会更新真实效果。预览页面只生成在 `.local-studio/preview-端口/`，不会发布到博客。
- 编辑博文或随想时点击「AI 讨论」，可收起面板、取消请求、新建讨论，或使用 ⌘Enter 发送。按文章分别保留本次会话文字记录；不会自动修改或保存正文。
- 发送前可切换「附带当前正文」，并从当前正文 / 封面引用的本地图片中勾选附件。支持 Markdown 图片、引用式图片、静态 HTML img 与封面；动态 MDX 表达式和远程图片不自动读取或下载。单张最多 4 mb，每次最多 4 张、总计 10 mb。PNG / JPEG / WebP / GIF 以 Anthropic Messages 原生 image 内容块发送。
- 使用当前模型设置，显示配置模型与实际返回模型。是否能理解图片取决于所配置模型和服务商。已用用户指定的 claude-opus-4-8 接口实际验证合成正文与公开猫咪图标，返回正确的图像描述和正文主题。
- 对话最多九轮，单条消息最多 2 万字符、历史合计最多 8 万字符、正文上下文最多 20 万字符。关闭正文不撤回之前发出的内容；新建讨论会清空本次会话。含未完成问题或会话记录时保留 WebKit 编辑现场，避免节能常驻丢失讨论；真正退出应用后会话清空。
- 聚焦名称已清理旧 local studio 应用的 Launch Services 注册，旧构建备份改为 `.app.legacy`；安装版同时更新主程序名称、中英文本地化名称与应用版本。系统索引刷新后显示 Tidemark。

## 编辑、讨论与发布

- 编辑页的 Markdown / 富文本切换位于格式工具栏，紧邻图片拖入提示。正文独立滚动，标题、摘要、工具栏、页面按钮保持固定；文档属性单独滚动。开启讨论或窗口较窄时，通过「文档属性」打开属性面板。
- 富文本支持标题、强调、列表、任务列表、表格、代码、图片和 Markdown 输入规则。切换模式本身保留原文；编辑后按 Markdown 序列化。公式、组件、导入语句及其他 MDX 源码以可编辑的保护块保留，公式使用 KaTeX 显示。
- 「插入组件」在编辑页打开浮窗，列出原组件的效果、参数及使用示例，插入时自动补 import 并转换为 MDX。
- AI 回复以 Markdown 显示，支持 GFM 表格、代码与公式，过滤原始 HTML 和危险链接。发送历史只使用回复原文；回复图片显示为链接，避免自动加载远程图片。
- 「发布网站」先显示整个项目的 Git 改动与实际 d 脚本，确认后执行 `bun run d`。当前脚本会先获取远程更新；有本地改动时先构建并提交，再合并远程记录。合并后重新构建最终版本，成功推送 main 后才部署 Worker。实际文件冲突会自动撤回本次合并、保留本地提交并列出冲突文件；推送被并发更新拒绝时停止部署，可重新发布。运行时显示有长度上限的输出，只在发布进行中轮询；发布失败显示退出码和输出，可重新检查后重试。应用在发布完成前阻止退出。开发验证使用替代执行器，没有执行真实发布。

## 系统小组件与快速写作

- macOS 14 及以上：在桌面右键选择「编辑小组件」，搜索 Tidemark，添加「快速写作」。支持小号与中号，均提供「写随笔」「写博文」入口；小组件仅显示固定入口，不读取文章、不调用模型、不定时刷新。
- 两个入口分别通过 `tidemark://new/thought` 与 `tidemark://new/writing` 唤起应用。支持冷启动、菜单栏常驻及节能释放后的恢复；编辑器就绪后才处理新建请求。随笔聚焦正文，博文聚焦标题，沿用当前界面的语言选择。
- 当前文档有改动时先备份草稿。发布、上传、组件编译未结束、frontmatter 无效或仍有译文待保存时，保留当前现场并提示处理后重试。
- 原生构建使用 Xcode 的 Widget Extension target，自动选择钥匙串中已有的 Developer ID Application 或 Apple Development 证书进行本机签名。需要完整 Xcode；不创建开发者账号、不上传构建、不申请 App Group，也不向小组件授予文件或网络权限。小组件扩展只启用 App Sandbox。
- 菜单栏图标由博客猫咪图标生成 RGB 透明蒙版并裁去外围留白；构建时检查实际编码后像素的透明度，防止生成全透明图标。应用以系统模板图像方式显示，跟随菜单栏深浅色。
